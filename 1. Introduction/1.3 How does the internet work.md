## Introduction to the Internet

### what is a switch and why do we need it?

Say you have 7 pc and your boss wants all these pc to be able to communicate with each other. But how to get all these PCs to comm with each other. This is where the **switch** come into play. The Switch is the device we used for computers/PCs in the same environment to comm with each other. When talking about same environment, it means that computers in the same office, house or work.


Now, we have 7 PC and a switch device, can the PC communicate with each other? No because these PC are not connected to each other and in order to fix that, we need cables to connect these PC to the switch. The typical cables are the copper cable (CAT5 or CAT6). In addition to this, some switch device support fiber optic cable as well and fiber optic cables are generally faster compared to copper cables.

*P/S, CAT means category and the higher the number, the faster the speed*

Also, please note that if there is switch in the environment, and if you want to connect computers to that switch, you must def use a cable that has generally a copper cable or fiber optic cable. Switch only works with cable.

However, if you want to connect PC in the same environment by using the wireless technology, you can use an **Access Point** device (AP). The only difference between AP and Switch is that AP is wireless and switch is using wired cables be it copper or fiber optic.
